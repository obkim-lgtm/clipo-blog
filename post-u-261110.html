창체 자료를 학생마다 여러 개 올리고, 세특 기록은 더 구체적으로 만들어요

2026. 11. 10.

창의적 체험활동은 학생마다 활동지·보고서를 여러 개 올려 한꺼번에 분석하고, 자율·진로활동도 활동을 여러 개 만들 수 있어요. 수업 세특은 평가하는 말보다 학생이 실제로 한 활동을 중심으로, 고른 분량에 맞춰 써요.

창체 자료를 학생마다 여러 개 올릴 수 있어요

지금까지는 학생 1명당 자료를 1개만 등록할 수 있어, 새로 올리면 이전 자료가 바뀌었어요. 이제 활동지·보고서를 여러 개 올리면 기존 자료에 더해지고, 올린 자료를 한꺼번에 분석해 기록할 활동을 추천해요. 파일은 1개당 20MB, 학생 1명당 합쳐서 60MB까지 올릴 수 있어요.

학생별로 받은 파일은 [일괄 자료 추가]에서 한 번에 올려 보세요. 파일 이름에 학생 이름이 있으면 학생과 바로 연결돼요.

자율·진로활동도 활동을 여러 개 만들 수 있어요

지금까지 자율·진로활동은 학급마다 1개라, 2학기 자료를 올리면 1학기 자료가 바뀌었어요. 이제 동아리활동처럼 활동명을 정해 학기·프로그램별로 여러 개 만들 수 있어요.

활동을 만들 때 한 학급 전체를 넣거나, 동아리·이동수업처럼 여러 학급에서 학생을 골라 넣을 수 있어요. 이미 만든 활동은 학급명이 활동명으로 그대로 남아 있어요.

수업 세특에 학생의 실제 활동이 더 구체적으로 담겨요

"리더십이 돋보임"처럼 평가하는 말을 늘어놓기보다, 학생이 어떤 활동에서 무엇을 했는지를 중심으로 써요. 과장된 표현은 줄였어요.

활동이 여러 개면 활동마다 흐름이 섞이지 않게 차례대로 정리해요. 피드백에 적힌 보완할 점을 학생이 이미 해낸 일처럼 쓰지 않아요.

고른 분량에 더 정확하게 맞춰 쓰고, 따옴표나 가운뎃점 같은 기호와 영문·한자처럼 생활기록부에 옮기며 자주 고치시던 표기는 처음부터 쓰지 않아요.

새로 만들거나 다시 만드는 기록부터 적용돼요. 이미 만든 기록은 그대로예요.
